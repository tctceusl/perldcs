========================================================
(iv) DEFAULT VLAN NAMES ASSIGNED TO SWITCHES
========================================================

By factory default, Cisco 2960 switches have these VLANs:

  VLAN ID  |  Name
  ---------|---------------------
  1        |  default
  1002     |  fddi-default
  1003     |  token-ring-default
  1004     |  fddinet-default
  1005     |  trnet-default

NOTE:
  - VLAN 1 is the default native VLAN
  - All ports belong to VLAN 1 until manually assigned
  - VLANs 1002-1005 are reserved and cannot be deleted



========================================================
(vi) CONFIGURE VLANs ON ALL SWITCHES
========================================================

--------------------------------------------------
STEP 1: Create VLANs on ALL 3 switches (S1, S2, S3)
--------------------------------------------------
Run the same commands on S1, S2, and S3:

  Switch> enable
  Switch# configure terminal

  Switch(config)# vlan 10
  Switch(config-vlan)# name VLAN10
  Switch(config-vlan)# exit

  Switch(config)# vlan 20
  Switch(config-vlan)# name VLAN20
  Switch(config-vlan)# exit

  Switch(config)# vlan 30
  Switch(config-vlan)# name VLAN30
  Switch(config-vlan)# exit

--------------------------------------------------
STEP 2: Assign access ports on S1
--------------------------------------------------
  S1(config)# interface FastEthernet0/11
  S1(config-if)# switchport mode access
  S1(config-if)# switchport access vlan 10
  S1(config-if)# exit

  S1(config)# interface FastEthernet0/18
  S1(config-if)# switchport mode access
  S1(config-if)# switchport access vlan 20
  S1(config-if)# exit

  S1(config)# interface FastEthernet0/6
  S1(config-if)# switchport mode access
  S1(config-if)# switchport access vlan 30
  S1(config-if)# exit

STEP 3: Assign access ports on S2

  S2(config)# interface FastEthernet0/18
  S2(config-if)# switchport mode access
  S2(config-if)# switchport access vlan 20
  S2(config-if)# exit

  S2(config)# interface FastEthernet0/6
  S2(config-if)# switchport mode access
  S2(config-if)# switchport access vlan 30
  S2(config-if)# exit

--------------------------------------------------
STEP 4: Assign access ports on S3
--------------------------------------------------
  S3(config)# interface FastEthernet0/11
  S3(config-if)# switchport mode access
  S3(config-if)# switchport access vlan 10
  S3(config-if)# exit

  S3(config)# interface FastEthernet0/18

  S3(config-if)# switchport mode access
  S3(config-if)# switchport access vlan 30
  S3(config-if)# exit

--------------------------------------------------
STEP 5: Configure trunk ports (inter-switch links)
--------------------------------------------------
On S1 (both uplinks to S2 and S3 must be trunks):

  S1(config)# interface FastEthernet0/1
  S1(config-if)# switchport mode trunk
  S1(config-if)# exit

  S1(config)# interface FastEthernet0/3
  S1(config-if)# switchport mode trunk
  S1(config-if)# exit

On S2 (uplink back to S1):
  S2(config)# interface FastEthernet0/1
  S2(config-if)# switchport mode trunk
  S2(config-if)# exit

On S3 (uplink back to S1):
  S3(config)# interface FastEthernet0/3
  S3(config-if)# switchport mode trunk
  S3(config-if)# exit

STEP 6: Save config on all switches

(vii) CONFIGURE DHCP SERVER IN VLAN 10
========================================================

GOAL: PCs in VLAN10 (PC1, PC4, PC7) get IPs automatically.

--------------------------------------------------
STEP 1: Add a Server device to the topology
--------------------------------------------------
  - Drag a "Server" from End Devices
  - Connect it to S1 using Straight-Through cable on port F0/5
  - Configure the switch port:

  S1(config)# interface FastEthernet0/5
  S1(config-if)# switchport mode access
  S1(config-if)# switchport access vlan 10
  S1(config-if)# exit

--------------------------------------------------
STEP 2: Set static IP on the DHCP Server
--------------------------------------------------
  Click Server -> Desktop -> IP Configuration -> Static
    IP Address   : 172.17.10.1
    Subnet Mask  : 255.255.255.0
    Default GW   : (leave blank)

--------------------------------------------------
STEP 3: Configure DHCP Service on the Server
--------------------------------------------------
  Click Server -> Services tab -> DHCP
  Turn Service: ON

  Fill in the DHCP pool:
    Pool Name        : VLAN10_POOL
    Default Gateway  : 172.17.10.1
    DNS Server       : 0.0.0.0
    Start IP Address : 172.17.10.50
    Subnet Mask      : 255.255.255.0
    Max Users        : 50

  Click "Add" -> then "Save"

========================================================
(d) RIP ROUTING CONFIGURATION
========================================================

NOTE: RIP (Routing Information Protocol) is a Distance
Vector routing protocol. Version 2 supports VLSM and
classless routing. Each router advertises its directly
connected networks.

-------------------------------
ROUTER0 - RIP Configuration
-------------------------------
Router0# configure terminal
Router0(config)# router rip
Router0(config-router)# version 2
Router0(config-router)# network 192.168.10.0
Router0(config-router)# network 10.0.0.0
Router0(config-router)# no auto-summary
Router0(config-router)# exit
Router0(config)# exit
Router0# write memory

-------------------------------
ROUTER1 - RIP Configuration
-------------------------------
Router1# configure terminal
Router1(config)# router rip
Router1(config-router)# version 2
Router1(config-router)# network 192.168.20.0
Router1(config-router)# network 10.0.0.0
Router1(config-router)# network 11.0.0.0
Router1(config-router)# no auto-summary
Router1(config-router)# exit
Router1(config)# exit
Router1# write memory

-------------------------------
ROUTER2 - RIP Configuration
-------------------------------
Router2# configure terminal
Router2(config)# router rip
Router2(config-router)# version 2
Router2(config-router)# network 192.168.30.0
Router2(config-router)# network 11.0.0.0
Router2(config-router)# no auto-summary
Router2(config-router)# exit
Router2(config)# exit
Router2# write memory


VERIFY RIP IS WORKING (run on each router):
  Router# show ip route
  Router# show ip protocols
  Router# show ip rip database

Expected output in "show ip route":
  R = routes learned via RIP
  C = directly connected routes

  On Router0:
    R  192.168.20.0/24 [120/1] via 10.0.0.2
    R  192.168.30.0/24 [120/2] via 10.0.0.2
    R  11.0.0.0/8      [120/1] via 10.0.0.2


========================================================
(e) VERIFYING CONNECTIVITY - PING TESTS
========================================================

From PC0 (192.168.10.2):

  Ping within same network (should succeed immediately):
    ping 192.168.10.3     <- PC1 (same subnet)

  Ping across networks (requires RIP to work):
    ping 192.168.20.2     <- PC2 (through Router0->Router1)
    ping 192.168.20.3     <- PC3
    ping 192.168.30.2     <- PC4 (through Router0->Router1->Router2)
    ping 192.168.30.3     <- PC5

  Ping router interfaces:
    ping 192.168.10.1     <- Router0 Fa0/0 (default gateway)
    ping 10.0.0.1         <- Router0 Serial2/0
    ping 10.0.0.2         <- Router1 Serial2/0
    ping 11.0.0.1         <- Router1 Serial3/0
    ping 192.168.20.1     <- Router1 Fa0/0
    ping 192.168.30.1     <- Router2 Fa0/0

Steps in Packet Tracer:
  1. Click PC0 -> Desktop -> Command Prompt
  2. Type: ping 192.168.30.3
  3. You should see 4 successful replies

Alternatively use PDU (Packet):
  1. Select the envelope icon (Add Simple PDU)
  2. Click source PC then destination PC
  3. Check the result in the bottom panel
